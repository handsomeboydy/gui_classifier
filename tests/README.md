# 测试说明

本目录提供分图工具核心分类规则的脱敏回归测试。

## 运行方式

在根目录执行：

```powershell
python -m unittest discover -s tests -v
```

## 覆盖范围

- `side_parser`：整线、分段、单点、全角标点、非法输入。
- 手动分类：最近塔匹配、阈值内外、红外命名、空通道目录、侧别过滤、端点塔、坏图片、无 GPS、重复文件名、源文件不被修改、重复运行一致性。
- 自主通道提取：时间窗、通道归属、skip_ir 内容、无时间照片不进入通道。
- 自主第二阶段：skip_ir 跳过红外、精细化/红外分类、无时间 _V_ 照片仍分类、自主侧别过滤。
- skip_ir 生命周期：两阶段之间存在、清理后删除、完整流程重复运行一致性。
- 异常台账：空台账、缺必需列、非数字塔号（当前行为为抛出异常，任务 D 预检将改为友好提示）。

## 数据说明

- 所有坐标、线路名称均为虚构值（23°30'N / 113°15'E 附近），不含真实生产资料。
- 照片由 Pillow 合成（带 GPS 与可选拍摄时间），台账由 pandas 生成，全部落在临时目录，测试后自动清理。
